A **Kotlin** backend prototype exposing an API over the **NFT marketplace smart contracts on TON** (`MarketplaceContract`, `SaleContract`), built for the Libermall marketplace.

## Overview
Provides programmatic access to marketplace and sale contract state on TON. Companion to the on-chain contracts in [TON-NFT-Contracts](https://github.com/TegroTON/TON-NFT-Contracts).

## Tech Stack
- **Language:** Kotlin (JVM)
- **Build:** Gradle (Kotlin DSL)
- **Chain:** TON (NFT marketplace & sale contracts)
